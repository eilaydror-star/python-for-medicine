## איך עובדים

1. לוחצים על **Open in Colab** ליד הפרק.
2. מריצים כל תא עם **Shift+Enter**.
3. בכל תרגיל יש תא ריק לפתרון שלך. הפתרון המוסתר נמצא בתא שמתחתיו, ונפתח בלחיצה כפולה.
4. **כדי לשמור את העבודה:** בתפריט של Colab, **File → Save a copy in GitHub**, בוחרים את הריפו הזה ואת אותו שם קובץ, ולוחצים OK. השינויים שלך נשמרים כאן, ואפשר להמשיך מכל מחשב.

> ⚠️ אם תפתח מחברת ולא תשמור עותק, השינויים לא יישמרו.
